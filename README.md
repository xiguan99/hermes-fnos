# Hermes Agent for fnOS

[Hermes Agent](https://github.com/NousResearch/hermes-agent) 的飞牛 OS（fnOS）原生打包版，附一个独立的管理面板应用。

两个应用分开装、分开升级：

| 应用 | 说明 | 入口 |
| --- | --- | --- |
| **Hermes Agent**（本体） | 后端 + 官方 Web 界面，原生绑定端口 | 桌面图标 / `http://<NAS>:2280/` |
| **Hermes Panel**（面板，可选） | 运行状态、服务控制、版本、日志、配置、快照、授权、自更新 | 桌面图标（飞牛 Web 内打开）/ `http://<NAS>:2281/` |

本体与面板各自独立，不装面板也能正常用本体；面板只是管理与运维的入口。面板的桌面图标在飞牛 Web 桌面里以 iframe 打开，直连 2281 端口同样可用，留给排障。

---

## 系统要求

- 飞牛 OS（fnOS）x86_64
- 内存 4 GB 以上（本体进程约 100 MB，对话走你自己的模型服务）
- 可用空间：本体约 1.2 GB（含内置 Python 运行时），面板约 10 MB

---

## 安装

1. 应用中心 → 手动安装 → 选择 `hermes-agent_vX.Y.Z_x86.fpk`
2. 需要管理面板时，再装一次 `hermes-panel_vX.Y.Z_x86.fpk`
3. 装完从桌面图标或浏览器端口直接打开

本体首次启动会自动解出内置运行时并准备数据目录，通常 1～3 分钟。装完立即打不开是正常的，等首次初始化结束即可。

---

## 使用

### 本体：连接模型

打开 `http://<NAS>:2280/`，按引导连接模型服务商（OpenAI、Anthropic、Kimi、MiniMax 等均支持），也可以稍后在界面里配置。配置保存到数据目录的 `config.yaml`。

### 消息平台

飞书、Telegram、WhatsApp、QQ Bot、微信 ClawBot 等在界面「设置 → 渠道」里接入，各自的令牌填你自己的。

### 面板：能做什么

- **总览**：运行状态、版本、PID、内存、CPU、端口、网关延迟，一键跳转本体
- **运行控制**：启动 / 重启 / 停止本体（日常更新请走应用中心）
- **版本管理**：本体版本与官方最新代号（只提示，不改动）；面板自身版本
- **日志**：应用 / 网关 / Dashboard / 面板四类日志
- **配置**：模型服务商只读预览、`config.yaml` 预览
- **快照**：备份与恢复配置、会话、技能、记忆（恢复前自动留一份）
- **授权与访问**：面板访问密码、局域网放行策略
- **面板更新**：面板可独立升级，见下

面板密码只保护面板自己的入口；Hermes 本体的登录不归它管。

## 面板自更新

面板走独立版本线（1.x），可以在面板里直接升级：

1. 「面板更新」→ 检查更新
2. 有新版 → 安装更新：下载 → sha256 校验 → 解包探活 → 原子切换
3. 失败自动保留上一版目录 `panel_dist.bak-<版本>`，可一键回滚

下载走三路：加速源 → 备用加速 → 官方直连；每次都会校验 sha256，失败原因写在面板日志里。

本体的更新不走面板，请用应用中心升级本体 fpk。

---

## 升级与卸载

- **升级**：应用中心对同名应用点升级即可，数据目录（会话、技能、配置、记忆）保留
- **卸载**：应用中心卸载。默认保留数据目录；卸载向导里选择删除才会清理数据
- 两个应用可以只升一个：本体升级不影响面板，面板升级不影响本体

## 常见问题

**桌面图标打开是空白 / 404**

两个应用的入口形态不一样：

- **本体**：图标是端口直达（`http://<NAS>:2280/`），不走统一网关。空白就确认应用已启动、端口没被别的程序占用。
- **面板**：图标在飞牛 Web 桌面内以 iframe 打开（网关前缀 `/app/hermes-panel`）；网关异常时可以直接访问 `http://<NAS>:2281/` 排障，两种入口打开的是同一个面板。

**面板显示「Hermes 未运行」**

本体没启动，或端口不是 2280。到应用中心确认本体状态；如果改过本体端口，面板需要在面板设置里同步。

**本体启动很慢或一直正在启动**

首次启动要解压内置运行时，给它 1～3 分钟。长时间不动就看面板日志里的 `info.log`。

**局域网别的电脑打不开**

确认没有防火墙拦 2280 / 2281。面板默认允许局域网访问，可在「授权与访问」里收紧。

**面板密码忘了**

删掉面板数据目录下的 `panel-auth.json` 再重启面板，密码即被清除（面板数据目录在应用中心的「数据目录」里能看到）。

## 构建

仓库里只放源码与构建脚本，二进制走 Releases。

```bash
# 1) 从上游前端源码产出 Web 界面（需要 Node 22+，首次会装依赖）
bash scripts/build-desktop-web.sh

# 2) 打两个 fpk（会做前置校验与隐私扫描）
bash scripts/build-fpk.sh all      # agent / panel / all
```

产物在 `dist/`：

- `hermes-agent_v<ver>_x86.fpk`
- `hermes-panel_v<ver>_x86.fpk`
- `hermes-panel-res_v<ver>.tar.gz`（面板自更新用的资源包）

打包前需要把内置运行时放到 `fnpack/venv-bundle.tar.gz`（从已装好的部署里导出），这个文件不进仓库。

打包脚本会先做硬校验，任一项不通过直接中止：图标必须是 256×256 且不与仓库里其它应用的图标重复；面板的 `VERSION`、`manifest`、`fnshell.py` 三处版本号必须一致；本体的关键文件与隐私扫描必须通过。

目录说明：

```
fnpack/          本体 fpk 骨架（manifest / cmd / config / wizard / app）
fnpack-panel/    面板 fpk 骨架 + 面板服务端与前端
app/desktop-web/ 桌面端 Web 适配层（web-shim.js 等，自维护）
desktop-src/     上游前端源码子集（构建 desktop-app 用）
scripts/         构建与测试脚本
```
